# Чернетка опису Icecat

На прохання користувача додано редакторський перегляд нового опису, без збереження в товарі. Після точного зіставлення бренду/MPN та відхилення демодоступу береться GeneralInfo.SummaryDescription.LongSummaryDescription, або за його відсутності Description.LongDesc / ShortSummaryDescription. Вибирається один основний текст, а не обидва підсумки. Додаються унікальні BulletPoints.Values, із fallback на GeneratedBulletPoints.Values. Disclaimer зберігається як текст. Структура перевірена за офіційною документацією: https://iceclog.com/manual-for-icecat-json-product-requests/

Службові заголовки Bullet Points, Короткий підсумковий опис і Сумарний опис не переносяться. Числа, артикули, назви технологій та одиниці не переписуються для «красивішого тексту». Скрипти та активні елементи не виконуються: джерельний HTML перетворюється на текст, який екранується в абзацах/списках. URL і сторонні зображення до чернетки не включаються. Розмір джерельного тексту обмежено 40 000 символів і 60 пунктами; надмірна відповідь не обрізається мовчки.

## Переклад і межі

Це НЕ загальний машинний перекладач. Є обмежений перевірений словник російських технічних фраз, зокрема «Собственная разрешающая способность прэктора» → «Рідна роздільна здатність проєктора». Невідомий текст, мовні fallback та помилковий переклад Manual позначаються для редактора. fullTranslationVerified завжди false; automatic=false; збереження відсутнє. Мовна евристика не гарантує, що всі російські фрагменти виявлено.

Для точного Epson V11HB60042 окремо перевірено Manual focus/zoom: https://www.epson-africa.com/projectors/professional/business-education/eb-994f-v11hb60042 . Тільки для цього бренду й MPN фрази «Фокус: Керівництво» та «Тип зума: Керівництво» замінюються у чернетці на «Фокусування: ручне» / «Тип зуму: ручний». На інші модифікації це правило не поширюється. Профільна сторінка Epson Europe також підтверджує ручне фокусування і зум для EB-994F.

Поточний опис і manual_overrides залишаються без змін. Якщо опис редагувався вручну, перегляд попереджає про заборону автоматичної заміни. Для реального застосування потрібні редакторське підтвердження, резервна копія і журнал; цей етап їх не імітує.
