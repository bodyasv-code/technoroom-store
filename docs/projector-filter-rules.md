# Правила фільтрів проєкторів TECHNOROOM

- Проєктори Epson: якщо технологію проєкції не вказано, автоматично заповнювати `3LCD`. Правило задане власником магазину 12.10.2026.
- Не застосовувати це правило до принтерів, витратних матеріалів чи аксесуарів Epson.
- Явне значення технології з характеристик або опису має пріоритет над типовим значенням; ручні дані не перезаписувати.
- Лазерне джерело світла означає тип «Лазерний», але не визначає технологію матриці.
- Спрощений фільтр джерела світла: LED / WLED / «Світлодіод» → `LED`; RGB Laser / LED+LASER / LASER+LED → `Лазер`. Гібрид відноситься до «Лазер» лише для групування в магазині. Детальний запис виробника та ресурс роботи зберігаються без заміни на коротку назву.
- «Домашній» та інші призначення визначати лише за явними даними, не за яскравістю чи роздільною здатністю.
- У роздільній здатності зберігати лише стандарт або розміри матриці; не використовувати максимальну підтримувану роздільну здатність замість власної.

Реалізація: `public/projector-specs.js`; використовується імпортом, редактором товару та каталогом.
