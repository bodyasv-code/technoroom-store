# Механічне очищення характеристик — 2026-10-24

Статус: застосовано в production. Операція `catalog-spec-mechanical-20261024`.

Незалежна перевірка бази: 136 цільових рядків, 136 повних резервних копій, 136 збігів із очікуваними характеристиками після змін, 136 збігів початкових характеристик із резервними копіями, 0 змін сторонніх полів, RLS резервної таблиці увімкнено. Картка Canon 4331 також перевірена на публічному сайті: швидкість друку має окрему назву, ОС без приклеєного USB, адреса документа повна. Неоднозначні фрагменти залишені для наступної перевірки.

Тести: 80/80 автоматичних, 9/9 браузерних перевірок імпорту. Початковий JSON-план збережено як історичний знімок перед застосуванням; `applied:false` у ньому описує стан на момент формування плану.

Перевірено 3027 активних товарів усіх категорій, з них 1618 — оргтехніка.
Пакет: 136 товарів, 211 однозначних змін. Після пакета у 233 товарів залишаються автоматично виявлені ознаки проблем; це не повна перевірка технічної достовірності.

Правила: URL з поля http/https відновлюється повністю як документ постачальника; назви швидкості й зайва дужка масштабування виправляються лише для оргтехніки; приклеєний хвіст прибирається лише за повного збігу з уже наявним окремим полем. Конфлікти не перезаписуються. Роздільна здатність, пам'ять та неоднозначні уривки не вгадуються. Описи, ціни, залишки, зображення, активність не змінюються.

SQL вимагає існуючої захищеної резервної таблиці, зберігає повний рядок до зміни, блокує точні цільові рядки, перевіряє повний початковий JSON характеристик і всі сторонні поля. Застарілий знімок або побічна зміна скасовують увесь пакет. Повторний запуск відхиляється. Жодних змін RLS або схеми.

Приховані товари не доступні цьому публічному аудиту та не змінюються. Решта ручних перевірок — у JSON-плані; змішані поля залишено видимими, а не приховано.
