# Фото Icecat: контрольований імпорт

Адмінка → ERC API → код товару → «Фото з Icecat» → «Знайти доступні фото» → вибрати кандидат → переглянути → підтвердити відповідність → додати одне фото.

Налаштування: виконати `supabase/icecat-product-images-upgrade.sql` після наявних міграцій журналу та ручних правок. Функція працює лише для поточної адміністрації магазину, не надає доступу звичайним користувачам і нічого не змінює під час встановлення. Використовуються вже налаштовані серверні токени Icecat й наявне сховище product-images.

## Захист даних

- Власний акаунт Icecat, точний бренд + MPN, без демоданих.
- Лише типізовані публічні фото галереї; приватні, партнерські й логотипи не імпортуються. Без припущення, що Image.HighPic не є логотипом.
- Браузер отримує вміст вибраного зображення, не URL із content-token. Ключі залишаються на сервері.
- Зображення перевіряється перед додаванням. Підписане підтвердження прив’язане до користувача, картки, її поточних фото й SHA-256 файлу, дійсне 10 хвилин.
- Файл завантажується повторно перед записом: зміна вмісту, доступу чи картки зупиняє імпорт.
- HTTPS лише images.icecat.biz / objects.icecat.biz; редиректи заборонені. JPEG, PNG, WebP, до 2 МБ, щонайменше 250 × 250, не більше 40 мегапікселів. Великі оригінали відхиляються, а не стискаються без повідомлення.
- Шлях `products/icecat/ID/SHA256.ext`, upsert вимкнений. Повтор того самого імпортованого файлу не створює дубля. Візуальні дублікати й тотожні старі фото з іншими шляхами автоматично не визначаються.
- Головне фото й усі наявні елементи галереї зберігаються. Якщо головне відсутнє, використовується перше наявне фото або нове.
- Прив’язка та before/after журналюються атомарно; конкурентні зміни захищені CAS. Ціни, залишки, описи та характеристики не входять до патча.
- У разі втраченої відповіді немає автоматичного повтору. Файл, завантажений перед невдалою прив’язкою, не видаляється навмання: його шлях записано в параметрах запуску для перевірки.

## Джерела та межі

[Icecat Product JSON](https://iceclog.com/manual-for-icecat-json-product-requests/), розділи Image / Gallery / Authentication. Публічна картка з імпортованими фото показує джерело, повідомлення про права та посилання на [Open Content License](https://iceclog.com/open-content-license/). Вміст файлів не модифікується. Це не висновок про юридичну відповідність усіх можливих сценаріїв використання.

Оновлення при відкликанні доступу, планове оновлення всіх фото, масовий імпорт і автоматичний відкат галереї не реалізовані. Історія дозволяє перевірити before/after; відновлення галереї потребує окремого контрольованого процесу, без видалення файлів навмання.
