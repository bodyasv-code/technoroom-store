Ніякого правила на весь бренд. Для оновлення наявних записів звіряються ID, SKU і назва моделі, записується тільки `specifications` з перевіркою початкового JSON. A3+ не прирівнюється до A3 у характеристиках: вони об'єднані лише у фільтрі. Параметри сканування й копіювання не змінюються під виглядом формату друку.

## Захист імпорту

- Одна функція нормалізації використовується XML ERC/ASBIS, контентом ERC Excel та ERC API; той самий захист є перед злиттям характеристик наявного товару.
- Відомі SKU перевіряються разом із моделлю й типом пристрою; підтверджені режими виправляють старі неоднозначні записи. Попередні п'ять Canon і дев'ять Epson/HP включені. Там, де відсутність автоматичного дуплексу не доводить ручний режим, зберігається лише «Автоматичний двосторонній друк: Немає».
- Невідомі моделі з суперечливим дуплексом блокуються в попередньому перегляді, а не отримують вгаданий режим.
- Наявні характеристики мають пріоритет також над синонімами з джерела: захист сімейства дуплексу, формату друку, нормалізованих ключів проєктора. Нові відсутні характеристики додаються; інші поля не очищуються.
- Для сканера не додається режим двостороннього друку. У DS-70 окреме правило уточнює сканування.
- Попередні правила брендів, категорій витратних матеріалів, Epson 3LCD, роздільної здатності та джерел світла залишаються. Етикетка A3/A3+ належить лише UI фільтра, не імпортованій характеристиці.

## Застосовано та перевірено

16.10.2026 застосовано рівно 14 планів через штатну кнопку адмінки. Діалог показав ID, SKU та нові значення для кожного запису; запити змінювали тільки `specifications` із CAS-перевіркою початкового JSON. Повторне читання адмінки показало 0 активних товарів із суперечливими характеристиками замість 14. Кількість усіх товарів залишилася 5195, активних — 4814. Публічна картка HP 3103fdn (4557) показує «Двосторонній друк: Автоматичний».

Живий попередній перегляд ERC XML: перевірені 3G631A і P2500W пройшли перевірки; невідома модель із «Ручний» + «Є» заблокована. Живий попередній перегляд ASBIS XML: TS3640 (6670C007) пройшов перевірку; CANON peripherals відображено як Canon; невідомий SKU з єдиним «вручну (автоматичний)» заблоковано. За відсутності ціни показано збереження наявної ціни, як і раніше. Кнопка імпорту не натискалась, тестових записів у базу не створено. Після перевірки сторінку перезавантажено, тимчасовий тестовий вибір прибрано. API та Excel використовують ту саму функцію нормалізації; реальний імпорт через API/Excel не запускався.
