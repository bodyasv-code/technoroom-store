# ERC XML — підв’язка фото

Локальна Windows-програма для підготовки XML до імпорту.

1. Двічі натисніть `Запустити ERC XML Фото.cmd`.
2. Виберіть основний XML-каталог.
3. Виберіть Excel-файл ERC з колонкою `SKU`, `Код` або `Артикул`.
4. Натисніть «Створити XML із фото».

Програма зіставляє товари за SKU та для кожного SKU з Excel додає або оновлює поле `<image>`:

```xml
<image>https://www.erc.ua/i/goods/SKU.jpg</image>
```

Новий файл з’явиться поруч з оригінальним XML із суфіксом `-with-erc-photos.xml`. Вихідний XML не змінюється. Також створюється короткий файл-звіт `.report.txt`.

Підтримується формат `.xlsx`. Програма не завантажує зображення — лише готує коректні URL у XML.
