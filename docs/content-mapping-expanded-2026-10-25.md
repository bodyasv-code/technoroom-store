# Розширення відповідностей Icecat без запису товарів

База перевірки: публічні характеристики ID 159 / 247 / 4331 / 4530, прочитані GET з публічним ключем, та раніше переглянуті живі відповіді власного API через адмінку. Жодні токени, повні відповіді або приватні дані в цей документ не записуються.

До стартового словника додано 33 предметні відповідності: швидкості кольорового/чорно-білого друку, сканер, копії/масштабування, копіювальний дуплекс, окремі формати файлів та глибини кольору, наявність/місткість ADF, окремі лотки, мови принтера, факс, мобільний друк, оперативна пам'ять, частота процесора; для проєкторів — загальна яскравість, відстань, співвідношення сторін, фокус, тип/кратність зуму, окремі ресурси джерела світла, потужність лампи, режими шуму, сумарна потужність звуку й автономність.

## Складені поля

«Лотки» зі значенням подачі/прийому не прирівнюється до однієї місткості. Загальна пам'ять із кількістю сторінок не стає RAM. ADF з ємністю/дуплексом не стає одним булевим полем. Змішані формати файлів не стають окремо форматами документів або зображень. Глибина вхідного/вихідного кольору, шум різних режимів, ресурси звичайного/екорежиму не зливаються.

Ці збережені записи відображаються як relatedCurrent / «Пов'язаний контекст (не точна відповідність)». Статус related не означає збіг або нове поле; виводиться попередження не створювати дубль без перевірки. Ручні прапорці складених полів, включно з видаленими вручну значеннями, консервативно захищають пов'язані пропозиції. Оригінальні дані не змінюються й не розбираються на вигадані факти.

## Помітні розбіжності

У Canon 4331 поле «макс. кількість копій» містить 9999; Icecat повертає 999 копій. Тепер це налаштована відповідність і видимий конфлікт, а не два непов'язані поля. Це не схвалення одного з чисел: потрібне підтвердження виробника перед збереженням.

Спільний нормалізатор порівнює лише форматування. Для максимального числа копій допускаються повні форми «До 999» і «999 копій», але довільний текст не обрізається. Тип лампи, ресурс/режим та LED/ANSI/ISO не взаємозамінні.

## Межі

Усі рядки automatic=false; база не змінюється. Відсутні збереження та автоматичний імпорт. Це розширення основних відповідностей, а не повне покриття всіх властивостей у каталозі. Спірні значення та неповні переклади залишаються для перевірки. Регресійні тести перевіряють контекст, tombstones, незалежність компонентів, XSS, незмінність входів і відсутність записів.
